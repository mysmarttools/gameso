How to Play 2048

2048 is a number puzzle game where you combine matching tiles to create larger numbers.

Use the arrow keys on desktop or swipe on mobile to move all tiles in the same direction.

2048 Game Rules

  • 🔢 Match two identical numbers to combine them.
  • ⬆️⬇️⬅️➡️ Move tiles using arrow keys.
  • 📱 Swipe on mobile devices.
  • 🏆 Reach the 2048 tile to win.
  • 🔥 Try to achieve the highest possible score.
